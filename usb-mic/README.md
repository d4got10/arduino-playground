# USB-микрофон из Arduino + KY-037

Arduino оцифровывает звук с модуля микрофона и передаёт его по USB.
Скрипт на компьютере принимает сэмплы и выводит их в звуковое устройство.
Через виртуальный аудиокабель это превращается в микрофон для Discord,
Zoom, OBS и любых других программ.

```
[KY-037] --AO--> [Arduino A0] ==USB==> usb_mic.py ==> VB-Cable ==> Discord/OBS
```

## Честно о качестве

Звук будет **как у рации**: шумный и тихий. Причины:

- У KY-037/038 **нет усилителя**. Микросхема LM393 на плате — компаратор
  для цифрового выхода DO, аналоговый выход AO берётся прямо с капсюля, и
  сигнал там всего десятки милливольт.
- АЦП Arduino 10-битный, шаг ≈ 5 мВ. Тихий голос занимает всего несколько
  ступенек.
- Leonardo умеет быть USB-клавиатурой и мышью, но стандартное ядро Arduino
  не умеет USB Audio. Поэтому Windows не увидит плату как микрофон
  напрямую, и нужен скрипт-посредник.

Говори в 5–10 см от капсюля. Как сделать звук нормальным, написано в конце.

## Подключение

| KY-037 | Arduino |
|--------|---------|
| AO     | A0      |
| G      | GND     |
| +      | 5V      |
| DO     | не нужен |

Бери **KY-037** (большой микрофон), он чувствительнее KY-038.
Синий подстроечник на AO не влияет, его можно не крутить.

Скетч работает на **Leonardo** (порт быстрый, настоящий USB) и на
**Nano/Uno** (скорость порта 1 Мбод, задана в скетче и скрипте).

## Установка

1. Залей `usb_mic/usb_mic.ino` через Arduino IDE (Плата: Arduino Leonardo).
   После заливки **закрой монитор порта**, иначе порт будет занят.
2. Поставь Python 3 и зависимости:
   ```bash
   pip install -r host/requirements.txt
   ```
3. Проверка в колонках или наушниках (лучше в наушниках, иначе будет
   свист обратной связи):
   ```bash
   python host/usb_mic.py
   ```
   Внизу бежит индикатор: `DC` — среднее значение АЦП (должно быть где-то
   в середине, не 0 и не 1023), `размах` — насколько сигнал «шевелится».
   Если частота заметно ниже 16 кГц, сэмплы теряются.

## Превращаем в микрофон для программ

### Windows
1. Поставь бесплатный [VB-Audio Virtual Cable](https://vb-audio.com/Cable/).
2. Запусти:
   ```bash
   python host/usb_mic.py --device "CABLE Input"
   ```
3. В Discord/Zoom/OBS выбери микрофон **CABLE Output**.

### Linux (PulseAudio/PipeWire)
```bash
pactl load-module module-null-sink sink_name=arduino_mic
```
```bash
pactl load-module module-remap-source master=arduino_mic.monitor source_name=arduino_mic_src
```
```bash
PULSE_SINK=arduino_mic python host/usb_mic.py
```
В программах выбирай микрофон `arduino_mic_src`.

## Настройки скрипта

| Параметр | Что делает |
|---|---|
| `--gain 40` | громче (по умолчанию 20). Если индикатор пишет `CLIP!`, убавь |
| `--denoise 2` | сила шумоподавления (по умолч. 1.5; 0 — выключить). Первые 1.5 с после запуска **молчи**: скрипт запоминает шум |
| `--gate 0.02` | шумоподавитель: глушит фон, пока ты молчишь |
| `--record voice.wav` | заодно писать в файл |
| `--no-play` | не выводить звук (только запись) |
| `--port COM5` | если порт не нашёлся сам |
| `--list-devices` | показать звуковые устройства |
| `--rate 8000` | если в скетче поменял `SAMPLE_RATE` |

В скетче можно включить `USE_INTERNAL_REF 1`: это примерно вдвое повышает
чувствительность, но только если `DC` в индикаторе меньше ~500 (Leonardo).
Иначе сигнал будет упираться в потолок.

## Режим с усилителем Leonardo (по умолчанию включён)

У чипа Leonardo (ATmega32U4) есть встроенный усилитель на входе АЦП, но
он работает только в **дифференциальном** режиме: измеряет разницу между
двумя пинами. Поэтому на второй пин (A5) потенциометром подаём то же
напряжение, что и постоянная составляющая микрофона. Разница тогда равна
одному звуку, и он усиливается в 10 или 40 раз.

Подключение (в дополнение к микрофону):

| Потенциометр | Arduino |
|---|---|
| крайняя нога | 5V |
| другая крайняя | GND |
| средняя | A5 |

Желательно поставить конденсатор 10 мкФ между A5 и GND (полоска «−»
на корпусе идёт к GND): он гасит шум потенциометра.

Настройка:
1. Запусти `python host/usb_mic.py` и смотри на `DC`.
2. Крути потенциометр, пока `DC` не станет примерно **512**. Около 0 или
   1023 сигнал упирается в край шкалы, и звука не будет.
3. Если всё равно тихо, поставь в скетче `DIFF_GAIN 40` и перезалей.
   При 40x подстраивать придётся точнее: удобное окно всего ±0.12 В.

Чтобы вернуться в обычный режим без потенциометра, поставь `DIFF_MODE 0`.
На Nano/Uno этого усилителя нет, и скетч выдаст понятную ошибку.

## Если не работает

| Симптом | Что проверить |
|---|---|
| `DC` около 0 или 1023, размах 0 | провод AO или питание модуля |
| Порт занят | закрой монитор порта в Arduino IDE |
| Только шум, голоса не слышно | говори ближе, подними `--gain` |
| Треск и прерывания | `--latency 0.3`; на Nano проверь, что частота в индикаторе ≈ 16 кГц |
| Свист | ты слышишь себя в колонках: надень наушники или используй VB-Cable |

## Как сделать нормальный звук

Модуль с усилителем стоит копейки и подключается теми же тремя проводами,
код менять не нужно:

- **MAX9814**: с автоматической регулировкой усиления, лучший вариант для голоса.
- **MAX4466**: с ручной регулировкой усиления.

С ним звук будет на уровне дешёвой гарнитуры, а не рации.
